# 🍕 Italiana Pizzaria - Landing Page

Uma *landing page* moderna, responsiva e performática para a **Italiana Pizzaria**, uma pizzaria artesanal focada em pizzas de massa com fermentação natural e ingredientes selecionados em Salvador, BA.

🔗 **Link do Projeto:** [https://italianapizzaria.netlify.app/](https://italianapizzaria.netlify.app/)

---

## 📋 Sobre o Projeto

O objetivo deste site é apresentar o cardápio, os diferenciais da pizzaria, localização, horário de funcionamento e facilitar os pedidos diretos através do WhatsApp, proporcionando uma experiência agradável e intuitiva para o cliente tanto no desktop quanto no mobile.

---

## ✨ Funcionalidades e Destaques

- 📱 **Layout Totalmente Responsivo**: Otimizado para navegadores desktop, tablets e celulares (com menu de navegação dedicado a dispositivos móveis).
- 🍕 **Cardápio Interativo Otimizado**: Exibição organizada por categorias:
  - Pizzas Tradicionais
  - Pizzas Especiais
  - Pizzas Doces
  - Bebidas
- 💬 **Integração com WhatsApp**: Atalhos diretos e botões de chamada para ação (*CTA*) para realizar pedidos diretamente com a equipe.
- 🕒 **Status e Horários de Funcionamento**: Informações claras de expediente e prazos de entrega.
- ♿ **Acessibilidade e SEO**: Marcação HTML5 semântica, suporte a navegação por teclado (links para pular direto ao conteúdo) e imagens com textos alternativos (`alt`).

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Estilização responsiva, componentes visuais e layouts flexíveis.
- **JavaScript (Vanilla JS)**: Interatividade, controle do menu mobile e regras de status.
- **Netlify**: Hospedagem contínua e gerenciamento de implantação.

## 🔧 Como Executar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/italiana-pizzaria.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd italiana-pizzaria
   ```

3. **Abra o arquivo `index.html`:**
   Você pode abrir diretamente no navegador ou usar uma extensão como o [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VS Code para rodar um servidor local.

## 🛠️ Personalização

Para atualizar as informações da pizzaria no arquivo `index.html`:
- **Preços e sabores**: Altere os valores nas seções correspondentes do cardápio (`#cardapio`).
- **Número do WhatsApp**: Atualize os links `<a href="#contato">` para incluir o link direto do WhatsApp (`https://wa.me/55719XXXXXXXX`).
- **Bairros e horários**: Substitua os textos entre colchetes pelos dados oficiais de atendimento.
